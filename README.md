Este projeto consiste na criação de um banco de dados relacional para gerenciar as operações de uma oficina mecânica. O objetivo é criar uma estrutura de dados que organize o fluxo de trabalho, desde a chegada de um cliente com seu veículo até a finalização e o faturamento do serviço.

O sistema controla o cadastro de clientes, veículos, mecânicos, peças em estoque e os tipos de serviços oferecidos. A entidade central do modelo é a Ordem de Serviço (OS), que conecta todas essas informações, registrando os serviços a serem executados, as peças utilizadas e a equipe de mecânicos responsável.
